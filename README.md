# First Money Gold (FMG) Web Application

Official web application repository for **First Money Gold (FMG)** - Tamilnadu's #1 Gold Loan Partner.

## Features
- **Modern Responsive Design**: TailwindCSS styling with brand aesthetics and micro-animations.
- **Interactive FAQ System**: Accordion and real-time live search filter.
- **Franchise & Revenue Models Breakdown**: Detailed cards for Standard and FICO models with interactive actions.
- **Direct Connect Links**: WhatsApp and phone dialer integrations.
- **Offline & Local Friendly**: Bundled assets and fallback support.

## Tech Stack
- **Framework / Bundler**: [Vite](https://vitejs.dev/) + React / Vanilla JS
- **Styling**: Tailwind CSS + Custom CSS Variables
- **Icons & Fonts**: Plus Jakarta Sans, SVG Lucide Icons
- **TypeScript & Node.js**: TypeScript 5.8+ & Node 22+

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
